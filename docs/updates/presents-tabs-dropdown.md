# プレゼント一覧 タブUI改善（ドロップダウン化）

## 概要
`/presents` のジャンル切り替えタブを、現状の「横スクロール pill 型ボタン群」から「タップで一覧展開するドロップダウンセレクト」に変更する。

## 背景・目的
- 利用者にアナログ寄りの若年配層が含まれており、横スクロール可能であることが視覚的に伝わりづらいフィードバックがあった。
- 横スクロールを誘導する UI 強化（フェード／矢印／ヒント文）も候補だったが、よりタップ操作に馴染みのあるドロップダウン形式の方が誤操作なく目的のタブへ辿り着けると判断。
- 常に「現在選択中のタブ」が明示されることで、現在地が分かりやすくなる効果も狙う。

## スコープ
- 対象コンポーネント: `src/components/presents/PresentTabs.vue`
- 呼び出し元 `src/Pages/PresentsPage.vue` の `v-model` インタフェースは維持する（破壊的変更を避ける）。
- 管理画面側のタブ（`AdminTabList.vue` 等）は対象外。

## UI 仕様

### ヘッダー部（クローズ状態）
- 横幅: コンテンツ幅にフィット（左右 16px パディング配下）
- 高さ: 約 52px（タップしやすさを優先）
- 表示内容（左から）:
  1. 補助ラベル「ジャンル」（小さく、`$text-brown-light`）
  2. 現在選択中のタブ名（メイン、`$text-brown`、bold）
  3. 右端に下向きシェブロン `▼`
- 背景: `$white`、角丸 12px、`box-shadow` を薄く付与し「押せそう感」を強調
- `aria-haspopup="listbox"` / `aria-expanded` を付与

### 展開時
- ヘッダー直下にリスト（カード型）を表示
- 各項目:
  - 高さ 44px 程度
  - 選択中項目は `linear-gradient(90deg, #5c442a 0%, #ee7f81 100%)` 背景＋白文字＋左にチェック相当（`✓`）アイコン文字
  - 未選択項目は白背景＋`$text-brown` 文字
  - 区切り線（薄いボーダー）
- リスト全体に上下スクロールを許容（タブが極端に多い場合への保険）。基本は折り返しなしで全件表示。
- 外側タップで閉じる（document クリックリスナー）。
- ESC キーで閉じる（簡易対応）。

### アニメーション
- 開閉時に `max-height` と `opacity` をトランジション（200ms ease）。
- シェブロンは開閉に応じて 180deg 回転。

## 実装方針

### コンポーネント
- 既存 `PresentTabs.vue` を書き換える（命名・props・emit はそのまま）。
- props: `tabs: PresentTab[]`, `modelValue: string` （変更なし）
- emit: `update:modelValue` （変更なし）
- 内部状態: `isOpen: ref<boolean>`
- 算出: `selectedTab` = `tabs.find(t => t.id === modelValue)`
- メソッド:
  - `toggle()` 開閉トグル
  - `select(id)` 選択して閉じる、emit
  - `onClickOutside(e)` ルート要素外なら閉じる
  - `onKeydown(e)` ESC で閉じる

### ライフサイクル
- `onMounted` で `document.addEventListener('click', onClickOutside)` / `keydown`
- `onBeforeUnmount` で除去

### アクセシビリティ
- ヘッダー: `<button>` で `aria-haspopup="listbox"`, `aria-expanded`
- リスト: `role="listbox"`
- 各項目: `role="option"`, `aria-selected`

## 受け入れ条件
- [ ] タブ群が常に「現在のジャンル + ▼」の 1 行で表示される（横スクロール不要）。
- [ ] タップで全タブが縦リストで展開され、選択中タブが強調表示される。
- [ ] 選択するとリストが閉じ、ヘッダーの表示が更新される。
- [ ] 外側タップ／ESC で閉じる。
- [ ] タブが 1 件の場合もクラッシュしない（タップ可能だが項目が 1 つだけ表示される）。
- [ ] PresentsPage 側のロジック・スタイルは無修正で動作する。

## 動作確認手順
1. `/presents` を開き、初期状態で「ジャンル: 〇〇 ▼」と表示されることを確認。
2. ヘッダーをタップしてリストが下に展開されることを確認。
3. 別タブを選択 → リストが閉じ、表示中のプレゼントが切り替わることを確認。
4. 展開状態で外側／ESC で閉じることを確認。
5. タブ件数 1 件と多数件（10件以上想定）で表示崩れがないか確認。
